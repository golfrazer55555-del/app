# 깜빡 방지

자주 까먹는 일을 **잠금화면 메모 · 시간 · 장소 알림 · 카운트 · 타이머**로 챙겨주는 앱이에요.

| 폴더 | 내용 |
|---|---|
| [`android/`](android/) | **안드로이드 앱 '깜빡 방지' (메인)**: 잠금화면 메모, 시간대별 자동 변경, D-day, 장소 알림, 볼륨 버튼 카운트, 타이머, 위젯 |
| [`web/`](web/) | 웹앱(PWA) 버전: 이미지를 만들어 저장·공유 (배경화면 설정은 직접) |
| [`bg-remover/`](bg-remover/) | **배경 지우개** 웹앱(PWA): 사진 배경을 AI로 지워 투명 PNG로 저장 (기기 안에서 처리) |

설치와 사용법은 [`android/README.md`](android/README.md)를 보세요.
