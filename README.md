# 메모 배경화면

자주 까먹는 일을 **단색 배경화면에 적어두는** 웹앱(PWA)이에요.
메모를 쓰고 색을 고르면 폰 해상도에 맞는 PNG 이미지를 만들어 줘요.

## 기능 (MVP)

- 여러 줄 메모 입력, 줄 앞 기호(없음 / 점 / 체크박스 / 번호)
- 단색 배경 11가지 + 직접 고르기, 글자색은 배경에 맞춰 자동(흰색/검정)
- 글자 크기, 굵게, 정렬(왼쪽/가운데/오른쪽), 세로 위치 조절
- 잠금화면·홈화면에서 **가려지는 영역 표시**와 겹침 경고
- 이미지 크기: 내 화면 자동 감지 / 자주 쓰는 안드로이드 해상도 / 직접 입력
- `+ 오늘 날짜` 버튼으로 날짜 넣기 (예: `11월 20일 (금)`)
- **저장**(PNG 다운로드), **공유**(안드로이드 공유 시트로 포토·갤러리에 바로 보내기)
- 설정 자동 저장, 홈 화면에 앱으로 설치 가능, 오프라인 동작

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (라이트/다크 모드) |
| `app.js` | 캔버스 렌더링, 줄바꿈, 저장·공유, 설정 저장 |
| `manifest.webmanifest`, `sw.js`, `icons/` | PWA 설치 및 오프라인 지원 |

빌드 과정 없이 정적 파일만으로 동작해요.

## 로컬에서 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 열어요.

## 폰에서 쓰기 (GitHub Pages)

PWA 설치와 공유 기능은 **HTTPS**에서만 동작해요. GitHub Pages로 무료 배포할 수 있어요.

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, 브랜치와 `/ (root)` 선택 → Save
3. 잠시 뒤 나오는 주소를 폰 크롬으로 열고, **⋮ → 홈 화면에 추가 / 앱 설치**

## 배경화면으로 설정하기 (안드로이드)

1. **공유 · 배경화면 설정** → Google 포토 / 갤러리 선택 (또는 **저장**)
2. 포토·갤러리에서 이미지 열기 → **⋮ → 배경화면으로 설정**
3. 잠금화면 / 홈화면 선택
