# 깜빡 방지 (안드로이드)

**까먹지 않게** 도와주는 앱이에요. 세 가지로 챙겨줘요.

1. **눈에 보이게**: 메모를 잠금화면·위젯에 (버튼 한 번에 적용)
2. **때가 되면**: 시간대별 자동 변경, 날짜·D-day 자동 갱신, 타이머
3. **그 장소에서**: 장소에 도착하거나 떠날 때 알림
4. **몇 번 했는지**: 카운트(화면이 꺼진 채 볼륨 버튼으로 세기)

화면은 아래 탭 5개: 메모 / 일정 / 장소 / 카운트 / 타이머

## 기능

**기본**
- 메모 여러 개 저장: 카드를 누르면 바로 적용, 길게 누르거나 연필 버튼을 누르면 편집
- 새 메모 템플릿: 빈 메모 / 체크리스트 / 한 줄 다짐 / 큰 글씨 한 단어 / D-day 카운트 / 며칠째(카운트업)
- 적용할 곳: 잠금화면 / 홈화면 / 둘 다
- 글: 줄 앞 기호(없음·점·체크·번호), 크기, 굵게, 정렬, 세로 위치
- 글자색: 자동(배경·사진 밝기에 맞춤) / 흰색 / 검정 / 노랑 / 빨강 / 하늘, 글자 뒤 반투명 상자
- 배경: 단색 16가지와 직접 고르기, **갤러리 사진**(두 손가락으로 확대·이동, 어둡게, 흑백)
- **그림 그리기**: 펜 9색, 굵기, 지우개, 되돌리기·다시, 모두 지우기
- 실시간 미리보기: 잠금화면 시계·바로가기에 가려지는 영역 표시와 겹침 경고
- 폰 해상도에 맞춰 렌더링, 갤러리에 이미지로 저장(Pictures/메모배경)

**자동**
- 자동 문구: `{오늘}` → 11월 20일 (금), `{D-day:2026-12-25}` → D-35 / D-Day / D+3, `{며칠째:2026-01-01}` → 324일째
  - 편집 화면의 버튼과 달력으로 넣고 바꿀 수 있어요. 매일 자정 직후 배경화면과 위젯이 자동으로 갱신돼요
- 시간대별 자동 변경: "평일 오전 7:30엔 출근 전, 매일 오후 9시엔 자기 전"처럼 요일과 시간을 정해요
  - 재부팅하거나 시간이 바뀐 뒤에도 다시 예약하고, 놓친 변경은 따라잡아요
  - 정확한 시각에 바꾸려면 '알람 및 리마인더' 권한이 필요해요(앱에서 바로 켤 수 있어요)
- 지금 적용된 메모를 고쳐서 저장하면 배경화면도 자동으로 다시 만들어요

**장소 알림**
- 장소 근처에 **도착할 때 / 떠날 때 / 둘 다** 알림 (예: 마트 → '우유 사기', 집을 나설 때 → '가스밸브 확인')
- 장소 등록: 지금 있는 곳 / 주소·장소 검색 / 지도에서 누르기(OpenStreetMap, API 키 불필요)
- 반경 100m~1km, 장소마다 켜고 끄기, 같은 알림은 15분 안에 다시 안 보냄
- 장소마다 **잠금화면도 같이 바꾸기** 선택(알림 문구 그대로, 또는 고른 메모로)
- 필요한 것: 위치 '항상 허용', 알림 권한, (갤럭시) 배터리 사용 제한 없음, 'Google 위치 정확도' 켜기 — 장소 탭에서 바로 켤 수 있어요
- 위치는 휴대폰 안에서만 쓰여요. 주소 검색·지도 표시 때만 검색어/지도 위치가 휴대폰 주소 검색 서비스와 OpenStreetMap 서버로 전송돼요

**카운트**
- 카운터 여러 개(이름, 목표 횟수), 화면을 눌러 +1
- **볼륨 버튼으로 세기**: 화면이 꺼져 주머니에 있어도, 음악을 듣는 중에도 볼륨 ↑ +1, 볼륨 ↓ −1(또는 +1), 이어폰 버튼 +1
  - 소리 없는 미디어 세션을 켜 두는 방식이라, 세는 동안 볼륨 버튼은 소리 크기를 바꾸지 않아요
  - 진동으로 알려줘요: +1 짧게, −1 두 번, 10번째마다 조금 길게, 목표 도달 시 길게 두 번 + 소리
  - 알림(잠금화면에도 보임)에서 숫자 확인, −1/+1, 그만 세기
- **음악을 들으면서도 세기**: 음악이 나오면 볼륨 버튼이 음악 소리를 한 칸 바꾸는데, 그 변화를 알아채 세고
  소리 크기는 바로 되돌려요(음악은 멈추지 않음). 시작할 때 소리가 최대·최소면 한 칸 조정해요
- 앱의 카운터 화면이 열려 있을 때도 음악과 상관없이 볼륨 버튼으로 세져요

**타이머**
- 바로 시작(1·3·5·10·15·30분·1시간), 이름 붙여 직접 설정, 여러 개 동시에
- 일시정지·계속·+1분·취소, 알림에 남은 시간 표시
- 끝나면 잠금화면 위에 큰 '시간 끝!' 화면 + 고른 소리를 알람 볼륨으로 반복(최대 1분)
- 절전 모드에서도 정확한 시각에 울리도록 알람 시계 방식 사용, 재부팅 후에도 이어서

**알림 소리**
- 일반 알림과 구별되는 앱 전용 소리 4가지(맑은 차임·통통 마림바·종소리·삐삐 경고음) + 휴대폰 기본 소리
- 장소 알림 소리와 타이머 소리를 따로 고르고 미리 듣기, 진동도 다른 패턴(길게-짧게-길게)
- 선택: 무음·진동 모드에서도 장소 알림 소리 내기(알람 볼륨)

**백업 · 옮기기**
- 설정(⚙)에서 백업 파일(zip) 만들기 / 가져오기: 메모·사진·그림·일정·장소·카운터·타이머·소리 설정
- 권한(위치·알림 등)은 백업되지 않아서 새로 깐 뒤 다시 허용

**빠른 실행**
- 알림창 빠른 설정 타일 '깜빡 방지': 메모가 2개 이하면 누를 때마다 다음 메모로, 3개 이상이면 목록에서 골라요
- 홈 위젯: 지금 적용된 메모를 보여주고, 누르면 바로 편집 화면이 열려요
- 앱 아이콘을 길게 누르면 메모 4개가 바로가기로 나와요

## 설치

1. `memo-wallpaper-<버전>.apk`를 폰에 받아요
2. 파일을 열고, 처음이면 **출처를 알 수 없는 앱 설치 허용**을 켜요 (파일을 연 앱, 예: 내 파일·크롬)
3. 설치 후 '깜빡 방지' 앱을 실행해요

> 같은 서명 키(`keystore/`)로 빌드하므로 새 버전 APK를 그냥 덮어 설치하면 메모가 유지돼요.

### 잠금화면이 안 바뀌면 (갤럭시)
설정 → 잠금화면 → 배경화면 서비스(다이내믹 잠금화면 등)를 **사용 안 함**으로 바꿔 주세요.

## 빌드

필요한 것: JDK 17+, Android SDK (platform 35, build-tools 35)

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease        # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest      # 기능·렌더링·그리기 테스트, 화면 캡처 → app/build/screenshots/
```

## 구조

| 파일 | 역할 |
|---|---|
| `WallpaperRenderer.kt` | 메모 → 이미지 그리기 (줄바꿈, 기호, 정렬, 글자색) |
| `WallpaperApplier.kt` | 화면 해상도로 렌더링 후 `WallpaperManager`로 잠금/홈 화면에 적용 |
| `MemoStore.kt` | 메모·일정·설정 저장 (SharedPreferences) |
| `TextTokens.kt` | 날짜·D-day·며칠째 자동 문구 |
| `Scheduler.kt` | 시간대별 자동 변경, 자정 갱신, 재부팅 후 재예약 |
| `ImageStore.kt` | 갤러리 사진 가져오기, 그림 저장, 갤러리로 내보내기 |
| `MemoWidget.kt` | 홈 화면 위젯 |
| `Templates.kt` | 새 메모 템플릿 |
| `Place.kt`, `GeofenceManager.kt` | 장소 알림(위치 감지 등록, 도착·출발 처리, 알림) |
| `LocationHelper.kt` | 현재 위치, 주소 검색 |
| `Tools.kt`, `CounterService.kt` | 카운터, 볼륨 버튼 세기(미디어 세션 + 음악 소리 변화 감지), 진동 |
| `TimerManager.kt`, `RingActivity.kt` | 타이머 예약·알림·울림 |
| `Sounds.kt`, `res/raw/` | 앱 전용 알림 소리와 알림 채널 |
| `MemoTileService.kt` | 알림창 빠른 설정 타일 |
| `Shortcuts.kt`, `ApplyShortcutActivity.kt` | 앱 아이콘 바로가기 |
| `ui/` | 메모·일정·장소·카운트·타이머 탭, 편집·그림·지도·설정 화면 (Jetpack Compose) |

## 서명 키에 대해

- **배포용(2.4.0부터)**: 비공개 키 `keystore/release.jks` + `keystore/release.properties`.
  저장소에 올리지 않아요(.gitignore). 두 파일이 `android/keystore/`에 있으면 `assembleRelease`가 이 키로 서명해요.
  잃어버리면 같은 앱으로 업데이트할 수 없으니 안전한 곳에 따로 보관하세요.
- **공개 키** `keystore/memo-wallpaper.keystore`(비밀번호 `android`): 개발·테스트용.
  2.3.0까지 이 키로 배포했어요. 예전 설치본을 업데이트해서 백업을 만들 때만 `-PsharedKey`로 씀.

### 2.3.0 이하에서 2.4.0으로 옮기기(서명 키가 바뀜)
1. 공개 키로 만든 2.4.0(`-PsharedKey`)을 덮어 설치 → 설정 → 백업 파일 만들기
2. 앱 삭제 → 비공개 키로 만든 2.4.0 설치 → 설정 → 백업 가져오기 → 권한 다시 허용
